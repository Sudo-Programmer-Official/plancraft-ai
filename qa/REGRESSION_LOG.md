### Severity Levels
- **critical** — Blocks a release path, data loss, or security issue.
- **major** — Core functionality impacted, workaround possible but painful.
- **cosmetic** — Minor visual or UX inconsistency.

### Status Codes
- **open** — Reproduced, not assigned.
- **in-progress** — Fix underway.
- **blocked** — Awaiting dependency/clarification.
- **resolved** — Fix merged and verified.
- **closed** — No action required (false alarm / duplicate).
