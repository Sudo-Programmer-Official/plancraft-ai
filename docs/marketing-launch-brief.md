# Marketing Launch Brief — PlanCraft AI

## Priority Order
1. Screenshots and conversion
2. Launch and traffic

Formula: traffic x conversion = growth.

## First User
- Focus on busy students, developers, and builders who struggle with planning and execution.
- Do not market to "everyone."
- Keep the positioning narrow enough that the first user instantly self-identifies.

## Native Premium Messaging
- Native iOS and Android apps use web-managed premium upgrades.
- Do not describe premium as a native in-app purchase.
- Use simple trust-building copy in mobile surfaces:
  Upgrade to Premium
  Opens secure web checkout
- After upgrade, message the return flow clearly:
  Return to the app and refresh to sync your premium access.

## Launch Channels
### Product Hunt
- Use a clear tagline.
- Include a short demo GIF.
- Write a first comment that tells the founder story, not just feature bullets.

### Reddit
- Target: `r/productivity`, `r/GetDisciplined`, `r/Entrepreneur`.
- Use a story-led angle:
  I built an AI planner because I could not stay consistent...
- Story beats direct promotion.

### X / Twitter
- Use a thread format:
  I spent months building an AI planner that actually works...
  Here is what I learned.
- Focus on build journey, insight, and outcome.

## Activation Loop
- Install
- Value in under 30 seconds
- Habit formation
- Share
- More installs

If the user does not feel value inside the first session, growth dies even if launch traffic is good.

## Conversion Hook
- Show the first success moment before pushing paid conversion.
- After value is clear, present:
  Want smarter planning daily? Upgrade.
- Timing matters more than aggression.

## Screenshot Strategy Summary
- Lead with outcomes, not features.
- One message per screenshot.
- Use bold headlines with readable real UI.
- Keep the purple brand direction and high contrast.
