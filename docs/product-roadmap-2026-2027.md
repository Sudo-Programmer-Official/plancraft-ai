# PlanCraft AI - 12 Month Product Roadmap

Time window: April 2026 to March 2027

This roadmap is designed for the current shape of PlanCraft AI:
- Web-first product
- Capacitor mobile shells on iOS and Android
- Web-managed billing through Stripe
- Shared product logic across web and mobile

The goal is not to ship everything. The goal is to build a product people use repeatedly, trust enough to pay for, and recommend to others.

## Execution Rules

1. Ship weekly, not perfectly.
2. Measure before building the next major feature.
3. Kill or pause anything not improving activation, retention, or trust.
4. Real user behavior matters more than internal opinion.
5. Speed beats completeness while the product is still finding fit.

This roadmap only works if execution stays brutal and honest.

## North Star For The Year

By March 2027, PlanCraft AI should feel like:
- the fastest way to turn messy intent into an actionable plan
- a daily-use execution product, not just a capture tool
- reliable enough on mobile that users trust it for real reminders and planning
- strong enough on retention and premium conversion that growth compounds

## Strategic Priorities

1. Increase activation: get users to first value in under 30 seconds.
2. Increase retention: make planning and follow-through habitual.
3. Improve trust: reliability, reminders, sync, auth, and billing return flows must feel stable.
4. Grow monetization: premium should feel like a natural upgrade after clear value.
5. Build differentiation: voice-first AI planning plus execution loops, not generic task management.

## Success Metrics

These should guide prioritization throughout the year:
- Activation: percentage of new users who create their first useful plan in the first session.
- Retention: weekly active users returning to plan at least 3 times per week.
- Conversion: free-to-premium upgrades after the first successful planning moment.
- Reliability: reminder delivery success, auth success rate, and mobile sync stability.
- Depth of use: number of users using planning plus reminders plus calendar/workspace features together.

## Hard Targets And Decision Gates

These are starting targets. Adjust them once real baselines are clear, but do not remove the discipline.

- Activation target: 40%+ of new users create a first useful plan in the first session.
- Activation failure trigger: if fewer than 30% create a first plan by the end of Q1, treat Q1 as failed and stop expansion work.
- Retention target: 25%+ of activated users return multiple times per week by the end of Q2.
- Retention failure trigger: if retention is under 10% after sustained iteration, rethink positioning and habit loop design.
- Premium conversion target: 3% to 5% of value-experienced free users upgrade.
- Reliability target: 95%+ success for critical flows like auth return, billing return, and reminder delivery.

If activation is weak, stop and fix activation.
If retention is weak, stop and fix retention.

## Primary Growth Loop

The main loop for this year:

Plan created -> user gets value fast -> user returns -> user trusts reminders and planning -> user upgrades

Secondary loop to validate later:

Plan created -> user shares or invites -> new user installs -> new user creates first plan

The first loop matters more than the second one right now.

## Quarter Focus Rule

You can support multiple tracks, but each quarter only gets one real thing to win:

- Q1 = Activation
- Q2 = Retention
- Q3 = Expansion
- Q4 = Intelligence

Everything else in that quarter is support work.

## Quarter 1: April 2026 to June 2026

Theme: fix the product foundation and sharpen the first-run experience.

### Quarter focus
- Activation only.

### Primary win condition
- A new user can open the app and create a useful first plan in under 30 seconds.

### User behavior change
- User opens the app -> understands what it does -> creates first plan without confusion.

### Main goals
- Make onboarding faster and clearer.
- Reduce friction in auth, upgrade, and cross-platform use.
- Tighten the core daily planning loop.
- Put clean product analytics in place.

### Product priorities
- Redesign onboarding for faster first value.
- Improve the voice-to-plan flow so users understand the result immediately.
- Make the home/dashboard state clearer for first-time users.
- Improve empty states, success states, and upgrade prompts.
- Tighten the premium web-upgrade flow copy across mobile and web.

### Platform and reliability priorities
- Stabilize mobile auth and return-to-app flows.
- Improve Android and iOS deep-link reliability.
- Audit reminder setup reliability and edge cases.
- Clean up build, sync, and release hygiene for mobile.

### Analytics priorities
- Instrument first-session funnel:
  sign up -> first plan -> first task completion -> reminder setup -> upgrade view
- Track activation and drop-off points clearly.
- Add dashboard-level release visibility so deployed versions are easy to trace.

### Expected outcome by end of June 2026
- New users understand the product faster.
- Mobile shells feel less brittle.
- You know exactly where activation is failing.
- 40%+ of new users should reach first useful plan in session one.

## Quarter 2: July 2026 to September 2026

Theme: increase retention and daily habit formation.

### Quarter focus
- Retention only.

### Primary win condition
- Users come back repeatedly because the product helps them follow through, not just because they were curious once.

### User behavior change
- User returns without needing a manual push from the founder and starts building a planning habit.

### Main goals
- Turn first-use success into repeated use.
- Make the product useful across a full day, not just at planning time.
- Strengthen reminders and follow-through loops.

### Product priorities
- Better daily, weekly, and monthly planning continuity.
- Smarter carry-forward for unfinished items.
- Templates for recurring routines, planning styles, and common use cases.
- Weekly review and reflection flows.
- Better planner clarity for now, next, later, and overdue states.

### Reminder and habit priorities
- Stronger reminder controls and defaults.
- Better channel-level trust for push, WhatsApp, email, SMS, and call.
- Quiet hours, snooze, and recovery flows that feel dependable.
- More meaningful success feedback after task completion or follow-through.

### Monetization priorities
- Premium upsell after success moments, not before.
- Sharper premium value framing:
  reminders
  calendar-aware execution
  richer AI planning
  team/workspace collaboration
- Test upgrade placement and refresh/access sync experience.

### Expected outcome by end of September 2026
- A larger share of users comes back several times per week.
- The product feels more like a planning system than a single-use planner.
- Retention should be visibly improving toward the 25%+ target for repeat weekly use.

## Quarter 3: October 2026 to December 2026

Theme: build stronger collaborative and workspace value.

### Quarter focus
- Expansion.

### Primary win condition
- Existing users can pull teammates or collaborators into the product without breaking the calm solo experience.

### User behavior change
- A satisfied solo or owner user invites at least one other person because collaboration now feels useful.

### Main goals
- Make workspaces meaningfully valuable for teams and collaborators.
- Increase product depth beyond solo usage.
- Strengthen admin, role, and coordination flows.

### Workspace priorities
- Improve workspace onboarding and teammate invites.
- Sharpen roles and permissions.
- Make shared work more visible without destroying the calm personal experience.
- Improve workspace-level billing clarity and plan management.

### Team execution priorities
- Shared task ownership and clearer assignment status.
- Better reminders and follow-ups for teams.
- Cleaner workspace dashboards for activity, priorities, and execution health.
- Better admin controls and audit visibility where needed.

### Product positioning priorities
- Clarify where PlanCraft AI wins for founders, builders, and small teams.
- Build stronger product proof around calm execution, not generic project management.

### Expected outcome by end of December 2026
- Teams and workspace users have a reason to stay.
- Revenue potential expands beyond solo premium.
- Expansion should come from retained users, not from bolting teamwork onto a weak core loop.

## Quarter 4: January 2027 to March 2027

Theme: deepen the AI moat and compound growth.

### Quarter focus
- Intelligence.

### Primary win condition
- Users trust AI suggestions because they consistently improve execution quality, not because the app simply feels "AI-powered."

### User behavior change
- User begins accepting and relying on personalized suggestions instead of treating AI output as optional decoration.

### Main goals
- Make AI feel more personalized and useful over time.
- Increase conversion and retention through smarter assistance.
- Create product loops that make the app more valuable the longer it is used.

### AI and intelligence priorities
- Better planning suggestions based on history, context, and patterns.
- Smarter weekly summaries and next-step recommendations.
- Personalized planning defaults based on user behavior.
- Better task decomposition and prioritization help.
- Improved memory/context handling across sessions where appropriate.

### Growth priorities
- Better referral or sharing hooks once retention is stable.
- More polished store listing, screenshots, and launch assets based on real user language.
- Content and launch system tied to proven user outcomes.

### Monetization priorities
- Improve premium packaging based on actual usage patterns.
- Consider hybrid experiments only if web-managed billing remains too limiting.
- Tighten win-back and reactivation messaging.

### Expected outcome by end of March 2027
- PlanCraft AI feels distinctly smarter and more personal.
- Growth can compound because retention and product depth are stronger.
- Intelligence should improve core behavior, not add noise.

## Always-On Tracks

These do not belong to one quarter only. They should continue all year.

### Reliability
- Fix auth regressions quickly.
- Keep mobile app links and billing return flows working.
- Protect reminder delivery quality.
- Reduce platform-specific breakage.

### Design and UX
- Keep reducing cognitive load.
- Make success states obvious.
- Keep calm, trustworthy visual polish across web and mobile.

### Analytics and learning
- Review activation and retention every month.
- Track which upgrades happen after which success moments.
- Record user objections manually until stronger systems exist.
- Treat every release as a test, not just a shipment.

### Release discipline
- Keep deployment, versioning, and store submission predictable.
- Treat release operations as product infrastructure, not side work.

## What Not To Do This Year

To keep focus, avoid:
- rebuilding the app as separate native apps
- bloating the product into generic enterprise project management
- over-automating deployment before the manual release flow is stable
- adding too many premium features before the core retention loop is strong
- chasing broad audiences before the first user group is locked in

## Experiments System

The roadmap should run through experiments, not just shipping lists.

Each month, run a small number of clear tests:
- Test 1: onboarding or first-value improvement.
- Test 2: reminder, habit, or return behavior improvement.
- Test 3: premium timing, pricing context, or upgrade messaging improvement.

For each experiment, define:
- the user behavior you want to change
- the metric you expect to move
- the decision rule for keep, iterate, or kill

Avoid stacking too many experiments at once. Learn clearly or not at all.

## Failure Triggers

Be honest early:

- If activation is still below 20% after repeated onboarding work, rethink product positioning.
- If users do not understand the first-value moment, simplify the product story before building more.
- If retention remains below 10% after Q2 iteration, rethink the habit loop and user segment.
- If premium conversion remains weak after activation and retention improve, revisit packaging before adding more paid features.

Brutal clarity is cheaper than carrying the wrong strategy for six more months.

## Review Cadence

- Monthly: review activation, retention, and release quality.
- Quarterly: decide what shipped, what slipped, and what should be cut.
- After each release: record bugs, review friction, and update the handbook/playbooks.

## Suggested 90-Day Immediate Focus

If the roadmap needs to collapse into the next best moves right now, prioritize:

1. Onboarding and first-session activation.
2. Reminder reliability and follow-through loops.
3. Mobile auth, sync, and billing-return stability.
4. Product analytics for activation and conversion.
5. Premium upgrade timing after clear value.

That sequence gives the best chance of turning PlanCraft AI into a product that retains, converts, and compounds over the next year.

For the next 30 days, ignore Q2 to Q4 planning and focus on activation plus the first-value moment.
