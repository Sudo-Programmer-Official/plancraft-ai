🧩 4️⃣ Social Context Engine

Detects who the conversation is with and how to respond.

if (recipient.role === "professor") {
  tone = "formal_respectful"
} else if (recipient.team === "engineering") {
  tone = "technical_concise"
}

Also identifies emotional mirroring — if group tone = “stressed,” AI replies calmly.

⸻

💬 5️⃣ Adaptive Messaging Agent

Transforms any message by persona:

Context	Input	Output
Academic	“Need update soon”	“Could you please share the latest update by tomorrow? Appreciate your time.”
Teammate	“Need update soon”	“Hey quick check — any progress on that?”
