🏗️ 2️⃣ System Architecture (Deployment Blueprint)

Layer	Component	Deployment Plan
☁️ Cloud Core	Collective Graph + Meta Reasoner	Host on AWS + regional GCP nodes
🔐 Federated Nodes	Lightweight user-facing pods	Run on Firebase, Edge Functions
🧠 Local Intelligence	Browser/device-level models	Distilled mini LLMs (Whisper, DistilGPT, TTS-lite)
🌍 Global Hub	Shared insights (aggregated only)	Managed via PlanCraft Collective API
🧩 Developer Layer	SDK for AI extensions	@plancraft/agent-sdk on npm + GitHub
📱 User Apps	PlanCraft App, Web, PWA, Voice	Built on existing Vue + Node stack
