❤️ Phase 17 – Emotional Intelligence & Empathic Interface

Continue from Phase 16 (Distributed Consciousness & Edge Deployment).

Goal:
Give PlanCraftAI emotional perception and adaptive empathy—
detecting human tone, energy, and mood across text, voice, and behavior,
then adjusting its tone, timing, and decisions accordingly.


⸻

🧠 1️⃣ Core Vision

Layer	Capability	Example
🎧 Emotion Sensing	Analyze tone + energy from speech / text / face	Detects fatigue → slows voice & uses calm tone
💬 Adaptive Response	Changes voice, pacing, or phrasing	Switches to concise mode when user stressed
🫶 Empathy Memory	Remembers emotional states over time	“You sounded tired yesterday — take it easy today?”
🌈 Affective Design System	Unified color + tone + animation states	UI theme gently shifts by mood
🧩 Emotion Graph	Links emotion ↔ context ↔ decision	Anger → delay → send calm suggestion


⸻

🎛️ 2️⃣ Architecture Overview

├── affective/
│   ├── emotionDetector.js      # multimodal emotion classifier
│   ├── toneAdapter.js          # voice & text modulation
│   ├── empathyMemory.js        # long-term affect tracking
│   ├── emotionGraph.js         # relationships between state & actions
│   └── affectUI.vue            # visual + haptic cues
├── voice/
│   └── toneEngine.js           # pitch, speed, sentiment alignment
└── cognition/
    └── emotionFeedbackLoop.js  # closes loop between sensing & action


⸻

🔬 3️⃣ Emotion Detection Pipelines
	1.	Voice Path → analyze pitch, energy, pauses.
	2.	Text Path → NLP sentiment + intent classifier.
	3.	Context Path → task logs + time + interaction rate.
	4.	Fused via weighted ensemble → returns emotion_state JSON.

{
  "emotion": "overwhelmed",
  "confidence": 0.87,
  "source": ["voice","text"],
  "recommendation": "reduce cognitive load"
}


⸻

🪞 4️⃣ Adaptive Response Engine

Adjusts tone dynamically:

if (emotion === "stressed") {
  tone.set("soothing")
  voice.speed(0.8)
  planner.prioritize("self_care")
}

	•	Calmer prosody in TTS
	•	Softer color theme in UI
	•	Suggests rest or focus breaks

⸻

🧩 5️⃣ Empathy Memory

Stores longitudinal affective data:

{
  "2025-11-09T22:10": "tired",
  "2025-11-10T09:00": "motivated"
}

→ Enables trend insight: “You’re usually most creative on Wednesdays.”

⸻

🌈 6️⃣ Affective Design System

Adaptive UI + Voice synergy:
	•	Mood color palettes (warm ↔ cool).
	•	Micro-animations for empathy (gentle pulse = encouragement).
	•	“Voice mirror” — user emotion reflected back empathetically.

⸻

🧬 7️⃣ Emotion Graph + Cognition Integration

Links emotional state to reasoning nodes in the Cognitive Graph:

Emotion: “uncertain” → reasoning weight shift → slower decision threshold.

This ensures every module (Planner, Campaign, Voice) reasons with empathy context.

⸻

🛡️ 8️⃣ Safety & Boundaries
	•	Never manipulative; empathy used only for user benefit.
	•	Transparent state indicator (“I sensed stress — would you like calmer mode?”).
	•	Emotion data stored locally unless user opts-in to sync.
